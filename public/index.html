    GitHub 账号
    打开 GitHub

    登录由 GitHub CLI（gh）的设备码流程完成：在浏览器里输入验证码并授权后，这里会自动更新。凭据由 gh 保存，和终端共用，不经过 Nootify。

    飞书机器人
    保存前会先向飞书验证；密钥不会显示在页面上。

    App ID 和 App Secret 在飞书开放平台应用的「凭证与基础信息」页。优先级：环境变量、这里保存的凭据、MCP 配置文件。保存后机器人会用新凭据重新连接；密钥保存在状态目录的 state.json（权限 0600）。
