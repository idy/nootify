    GitHub 账号
    打开 GitHub

    在浏览器里输入验证码并授权后，这里会自动更新。令牌只保存在 Nootify 的状态目录（权限 0600），和终端里的 gh 互不影响，也不需要安装 gh。GitHub 没有私有仓库的只读授权，所以会申请 repo 和 read:org；Nootify 只发送只读查询。

        Nootify 内置 Tailscale 客户端，登录后会作为独立设备加入你的网络，无需安装系统客户端。其他设备可通过这个节点的 80 端口访问，无需填写端口号。默认仅允许同一账号的设备访问；设置只能在本机修改。
